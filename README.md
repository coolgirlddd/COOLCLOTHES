# COOLCLOTHES — интерактивный MVP

Это браузерный прототип COOLCLOTHES. Он подходит для демонстрации основных пользовательских сценариев и публикации через GitHub Pages.

## Запуск локально

1. Скачайте `index.html`.
2. Откройте файл в современном браузере.
3. Создайте демо-профиль.
4. Добавляйте вещи, собирайте образы, публикуйте их в ленте и создавайте запросы на подбор.

## Публикация через GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Дождитесь публикации и откройте адрес, который покажет GitHub Pages.

## Что уже работает в прототипе

- локальный демо-профиль;
- добавление фотографий вещей, сжатие изображений и попытка убрать однотонный фон;
- категории, сезоны, поиск и избранные вещи;
- конструктор образов с перемещением, масштабированием и слоями;
- сохранение и редактирование образов;
- лента вещей и образов, лайки, комментарии, подписки и сохранённое;
- запросы на подбор образа и ответы сохранёнными образами;
- список покупок и бюджет;
- демонстрационные каталоги брендов и бизнес-раздел;
- экспорт и импорт резервной копии данных.

## Важные ограничения

Сейчас это **клиентский демонстрационный MVP**, а не опубликованный многопользовательский сервис:

- профиль не защищён паролем и существует только в текущем браузере;
- данные хранятся в `localStorage` на устройстве пользователя;
- публикации не синхронизируются между разными людьми и устройствами;
- бренды, пользователи, товары, цены и бизнес-метрики в демо частично вымышленные;
- покупка и оплата не подключены;
- удаление фона работает приблизительно и лучше справляется с однотонным фоном;
- ИИ-подбор зависит от среды, в которой запущен прототип, и не гарантируется на GitHub Pages.

Для настоящих аккаунтов, общей ленты, совместного хранения фотографий и ролей потребуется backend (например, Supabase) с настроенными таблицами, хранилищем и правилами доступа (RLS). Не размещайте секретные ключи в публичном репозитории.

## Резервное копирование

Откройте **Ещё → Мой профиль → Скачать копию**. JSON-файл можно загрузить обратно через **Загрузить копию**. Храните резервную копию отдельно от браузера.
